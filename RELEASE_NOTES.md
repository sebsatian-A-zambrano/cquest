# CQuest · El festival de los faros

Una aventura nocturna con **14 mundos de Algoritmos y 14 de C**, decisiones, exploración, avatares y desafíos donde escribes y ejecutas código para avanzar.

- **[Jugar e instalar en el celular](https://sebsatian-a-zambrano.github.io/cquest/)**.
- Para PC, descarga **cquest-web.zip**, extráelo por completo y ejecuta `python start_game.py` con Python 3.
- El progreso se guarda localmente: SQLite en la descarga para PC e IndexedDB en el navegador o aplicación móvil. Sin cuentas ni base de datos en la nube.
- Usa **Mi partida** para descargar una copia y recuperarla en otro dispositivo.
- Desde **Instalar**, espera la confirmación de descarga completa para jugar y compilar código sin conexión.
- El ZIP incluye el compilador y todos los recursos. La aplicación móvil se instala desde el navegador; el ZIP no es un APK.

Comprobados los 28 desafíos, la recuperación de partida, la importación de copias y el compilador sin conexión.
